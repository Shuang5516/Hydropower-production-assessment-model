# Hydropower-production-assessment-model
MATLAB implementation of a stochastic runoff forecasting and cascade hydropower operation assessment framework developed in research at KTH Royal Institute of Technology.

## Overview

This framework investigates how hydroclimatic periodicity,
particularly biennial wet-dry runoff variability, influences
forecasting accuracy, hydropower production efficiency,
and energy generation.

The methodology combines:
- Stochastic runoff scenario generation
- Wet- and dry-year classification
- Cascade hydropower optimisation
- Receding-horizon operation planning
- Monte Carlo simulations
- Forecasting and production performance assessment
